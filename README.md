# Jewel Abimbola — Portfolio (React + Vite)

```bash
npm install
npm run dev     # local dev server
npm run build   # production build in /dist
```

## Where to edit
- `src/data/content.js` — contact links, projects (role/year/tools/cover/images/behance), process stages, WhatsApp link, photo
- `src/styles/global.css` — all styling and design tokens (CSS variables)
- `src/components/` — Nav, Hero, Work, Approach, About, Contact, Footer and small UI helpers
